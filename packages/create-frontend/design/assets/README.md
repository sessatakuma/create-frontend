# Brand assets

The bear PNGs are unchanged copies of Akuma's original `public/images/logo*.png`. Use them without recoloring, stretching or redrawing.

`social-icons.json` contains SVG strings keyed by Instagram, Threads, Facebook and GitHub, copied from Akuma's footer. Instagram and Facebook use the existing Lucide marks; their license is retained in [LUCIDE-LICENSE.txt](LUCIDE-LICENSE.txt). Threads and GitHub preserve Akuma's custom SVG paths. The service names and marks identify their respective services.

`fonts/fonts.css` and its 124 WOFF2 files are the Noto Sans JP subsets used by the calibration builds. CSS URLs resolve relative to that file. Use them for offline standalone prototypes, or load Noto Sans JP through the product's font integration. The font license is retained in [fonts/OFL.txt](fonts/OFL.txt).

Visual provenance is recorded in the [calibration notes](../docs/design-calibration.md). Source assets are kept separate from screenshot examples.
